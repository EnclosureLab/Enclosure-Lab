ENCLOSURE LAB — WEBSITE

WHAT YOU HAVE
- index.html: the website
- style.css: all visual styling
- script.js: quote-form behavior
- config.js: easiest place to edit business name, email, and tagline

HOW TO EDIT
1. Open config.js in a text editor.
2. Change businessName, tagline, and quoteEmail.
3. Save the file.
4. Open index.html in a browser to preview the site.

IMPORTANT
The current quote form is a front-end prototype. By default it creates an email draft using the quoteEmail address. It does NOT store orders in a database.

NEXT STEPS FOR A REAL BUSINESS SITE
- Connect the quote form to a form/email service or your own backend.
- Add photo/file uploads for subwoofer specs.
- Add an admin dashboard for quote requests.
- Add customer approval of designs.
- Add online payment after the quote is approved.
- Add shipping rates and tracking.
- Add an order-status page.

The site is intentionally built with plain HTML/CSS/JavaScript so you can edit it without a complicated framework.
